# Railway Reservation System

A Python-based Railway Reservation System developed using Tkinter. This application provides a graphical interface for searching trains, checking seat availability, booking tickets, and managing reservations.

## Features

- Search trains by source and destination.
- View available trains and their details.
- Enter and validate passenger information.
- Select seat preferences (Window, Middle, Aisle, or Any).
- Automatically calculate ticket fares.
- Simulate payments through UPI, Card, and Cash.
- Generate unique 10-digit PNR numbers.
- Book and cancel tickets using PNR numbers.
- View all current bookings.
- Validate journey dates and passenger details.

## Technologies Used

- Python
- Tkinter
- Tkinter.ttk
- Random module
- Datetime module

## Installation

Clone the repository:

```bash
git clone https://github.com/saptaparnadey/Railway-Reservation-System.git
```

Navigate to the project directory:

```bash
cd Railway-Reservation-System
```

Run the application:

```bash
python railway.py
```

## Important Notes

- This is an academic project and not an official railway booking platform.
- Payment functionality is simulated.
- Train details and fares are predefined.
- Booking records are stored in Python lists and are not permanently saved.
- All booking data is lost when the application closes.
